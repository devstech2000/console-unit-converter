# console-unit-converter
This is my second project from scratch. I studied the documentation on studyPlan.dev and learncpp.com, after that I created my own documentation.
Only with my own documentation did I build this unit converter in C++.

With this unit converter you can convert celsius into fahrenheit, kilometer into miles and kilogram into pound. 

If you start the unit converter you can type in a number from 1 to 4, to choose which converter do you need, you can also exit the program with the number 4. 

If you enter a number that is not included, you will receive an error message and a hint about which numbers are included.
